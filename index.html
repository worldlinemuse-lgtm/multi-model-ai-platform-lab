Encrypted vault portability
Export contains AES-GCM ciphertext, random salt, IV, and KDF parameters only; it never contains plaintext API keys. Keep the original passphrase to unlock the backup on another device. Importing a backup replaces this browser's saved vault only after confirmation.
Change vault passphrase
